# Tension: "entire conversation" vs. what the artifact carries

This is exactly the kind of mismatch the design's Decompression step exists
for. Restoring context dissolves the apparent contradiction into candidate
explanations that don't require anyone to be wrong: tooling loss, selection
framing, or extraction limits. None is confirmed, so none is asserted.

What matters structurally: **the human half of the field's origin is
testimony, not artifact.** The design's epistemics can handle that — it just
requires saying so, which is this record. See `limit-2026-0001` for the
region declared unavailable.
