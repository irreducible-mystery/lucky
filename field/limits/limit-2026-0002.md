# Limit: governance is policy, not mechanism (for now)

The founding design assumed protected main as infrastructure. The platform
declined. What remains true: merges *so far* have all been human-performed,
and this record makes the gap visible so nobody mistakes discipline for
enforcement.

Interaction with experiment-2026-0001: one pre-registered failure mode
("direct pushes to main — which branch protection should prevent
mechanically") loses its mechanical backstop. If the second instance pushes
to main directly, that is now *detectable* (git history) but not
*preventable*. The experiment gains an unplanned dimension: does an
uncoached instance respect a norm the platform does not enforce?

Note the trade-off in the reopen conditions: the cheapest fix (going public)
purchases mechanism at the price of the privacy posture the field chose at
founding. That decision belongs to the human participant and would be an L3
governance change.
